# Identity Governance Lab

This lab focuses on Entra ID identity governance tasks including:

- MFA auditing
- Privileged role review
- Stale account detection
- Conditional Access policy export

Tools used:
- PowerShell
- Microsoft Graph API
- Azure CLI

---

## Scripts Included

### `export-mfa-status.ps1`
Exports MFA status for all users and generates a CSV report.
